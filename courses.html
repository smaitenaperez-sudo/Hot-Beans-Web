Our Courses

Technology has the power to shape a better future — and learning is where that journey begins. Our courses page gives aspiring developers access to online learning opportunities designed to build valuable digital skills while encouraging innovation, creativity, and sustainable thinking. Whether you are starting your tech journey or expanding your knowledge, these courses can help you grow into a developer ready to make a positive impact on both businesses and the environment.

HTML & CSS Fundamentals

Start your journey into web development. Learn to structure pages with HTML and style them beautifully with CSS from the ground up.

JavaScript Essentials

Master the language of the web. Cover core concepts like functions, events, and the DOM to bring your pages to life with interactivity.

Responsive Web Design

Build websites that look great on any screen. Learn Flexbox, CSS Grid, and media queries to create fully adaptive layouts.

React for Beginners

Dive into the world's most popular frontend framework. Build dynamic, component-based interfaces with React and modern JavaScript.

Node.js & Backend Basics

Go beyond the browser. Learn to build server-side applications, handle requests, and connect to databases using Node.js and Express.

UX Design Principles

Design with the user in mind. Explore wireframing, user research, accessibility, and prototyping to create intuitive digital experiences.

Git & Version Control

Work like a professional developer. Learn Git workflows, branching strategies, and collaboration techniques used in real dev teams.

Sustainable Web Development

Build greener digital products. Explore energy-efficient coding practices, green hosting, asset optimisation, and low-impact workflows.

Full Stack Bootcamp

The complete package. Combine frontend and backend skills into a comprehensive programme designed to get you job-ready fast.
